# Daily Motivator Bot

** Telegram-бот для планирования, доминирования и генерации контента в нише фемдом / финдом**

Бот помогает вести Telegram-канал, следить за задачами, даёт идеи для постов, фото и кружочков, а главное — заёбывает матом, чтобы ты делала дела.

---

## 🚀 Возможности

### Ежедневная рассылка
- Каждый день в **13:00** МСК бот присылает:
  - план на день из расписания
  - идею для поста
  - идею для фото / видео
  - мотивацию
  - текущий список напоминаний

### Напоминания
- Добавление списком с номерами
- Удаление одного или нескольких (через пробел)
- Редактирование текста
- Поиск по напоминаниям
- Статистика (количество, средняя длина)
- Экспорт в текстовый файл
- Отмена последнего действия (`отмени`)

### Генерация контента
- `/ideapost` — идея для поста
- `/ideacontent` — идея для съёмки (фото)
- `/ideavideo` — идея для кружочка (видео)

### Расписание задач
В файле `tasks.py` задано недельное расписание, которое учитывается в ежедневной рассылке:

- понедельник — запись контента
- вторник — пост в канал
- четверг — кружочек
- пятница / суббота — пост-зазывалка

### Жёсткая поддержка
Любое сообщение без команды воспринимается как отмазка. Бот отвечает грубо, матом, но с заботой — и всегда напоминает, что ты делаешь это ради себя.

## 📋 Команды бота

| Команда | Что делает |
|---------|-------------|
| `/start` | запустить бота |
| `/ping` | мотивация прямо сейчас |
| `/status` | список напоминаний |
| `/nextday` | перенести задачу на завтра |
| `/ideapost` | идея для поста |
| `/ideacontent` | идея для фото |
| `/ideavideo` | идея для кружочка |
| `/com` | список команд |
| `добавь в напоминания: …` | добавить напоминание (можно списком с номерами) |
| `удали напоминания 1 3 5` | удалить несколько |
| `измени напоминание 2 на …` | изменить текст |
| `найди напоминание …` | поиск по тексту |
| `статистика` | статистика напоминаний |
| `экспорт` | выгрузить напоминания в файл |
| `отмени` | отменить последнее действие (добавление или удаление) |
| `план на день` | показать задачу из расписания |

## 🧠 Используемые технологии

- **Python 3.12**
- **DeepSeek API** (основной провайдер) + **Groq** (опциональный резерв)
- **python-telegram-bot** (не используется, бот написан на чистом `requests`)
- **systemd** — автозапуск и перезапуск бота
- **Digital Ocean** — хостинг
